# Food image folder

Place your food and meal-category images in this folder.

- Food image convention: `<lowercase-food-name>.webp` (for example,
  `chicken_adobo.webp`).
- Meal categories: `category_breakfast.webp`, `category_lunch.webp`,
  `category_dinner.webp`, and `category_snack.webp`.
- Use a `.png` instead by updating the matching path in
  `lib/core/app_image_assets.dart`.

The application shows **Image here** until a matching image is available.
